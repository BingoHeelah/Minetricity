Minetricity
===

This mod aims to add both AC (including 3 phase) and DC simulation for minecraft 1.21.1 

It is rooted in both an educational and survival standpoint. Touch a live wire? ZAP! Too much current flowing through a wire? You just might start a fire. And if you're feeling extra spicy, grounding out a high current device will give you a fireworks show of a lifetime.

Please note that this mod is in a **very** alpha state. It is far from survival ready.
